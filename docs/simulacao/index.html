🏦 Bancos

⚙️ Instalar o botão "Preencher Carmax" (só uma vez por computador)
1
No Chrome do computador, deixe a barra de favoritos visível: Ctrl + Shift + B.
2
Arraste este botão vermelho para a barra de favoritos:
Preencher Carmax
Se não der para arrastar: clique com o botão direito em "Preencher Carmax" → Copiar endereço do link. Depois, na barra de favoritos, botão direito → Adicionar página → Nome: Preencher Carmax · URL: cole.
3
Na primeira vez em cada banco, o Chrome pergunta se pode ler a área de transferência. Clique em Permitir.

O botão só preenche os campos. Ele nunca clica em Simular nem envia proposta. Você confere e envia.

Os dados dos clientes ficam só neste aparelho e navegador.
